# Appendix C: v5.0.0-rc1 Release Notes {#release-notes}

**Release Date:** 23 October 2026

I> The primary goals of this release were a new Bootstrap 5.3 interface, the removal of long-deprecated code and features, and a sweep of security and data-integrity fixes. This release removes the deprecated functions and class aliases, the old themes, PDF output and file check-in/check-out. Add-on modules and customizations that still depend on any of these will need to be updated before upgrading.

## Downloading & Installing

The only official distribution site is [GitHub](https://github.com/web2project/web2project/releases). Check out the [installation chapter](#installation) to get started.

## Reporting Problems

For more information, support, or to discuss upcoming features, please visit [Discussions](https://github.com/orgs/web2project/discussions). Report any issues you find in the [issue tracker](https://github.com/web2project/web2project/issues), and mark feature requests as requests rather than bugs.

## New Features

* New Bootstrap 5.3 interface
  * Bootstrap 5.3.8 is bundled with the application, so no CDN is needed
  * NiceAdmin-style header, sidebar, colours and typography, using the bundled Nunito Sans and Poppins fonts and Bootstrap Icons
  * New sign-in, sign-up and lost-password pages
  * Layout tables replaced with Bootstrap markup in every module, the shared templates and the installer
  * Bootstrap is now the only theme, so the per-user and system-wide style settings are gone
* Projects
  * New "Tasks (All)" tab on the project view showing active and inactive tasks together in tree order (based on work by Klaus Buecher)
  * Inactive tasks now have their own row colour and an entry in the task key
  * Project budgets are shown on the project view again
* Tasks
  * The "show inactive tasks" link on the Tasks list now works, as a "show all tasks" / "show active tasks" toggle (based on work by Klaus Buecher)
  * Resources assigned on a task's "Other resources" tab are saved again; nothing had saved them since v3.2 (based on work by Klaus Buecher)
* Files
  * The Files list is grouped under project headings
  * The Files list hides files from projects and tasks the user isn't allowed to see
  * New Owner and Category filters on the Files page, next to the Project filter. The owner filter also narrows the counts on the category tabs
* Custom fields
  * Custom fields work on users
  * Calendar (event) custom fields work again

## Fixes/Bugs Closed

* Security
  * Fixed stored and reflected XSS in the selector popup. Option labels are now escaped in every dropdown built with arraySelect() and in the project dropdown
  * Public sign-up cleans the e-mail address before using it in the duplicate-address lookup (SQL injection)
  * Translation files are read with a parser instead of eval() ([#313](https://github.com/web2project/web2project/issues/313))
  * The translation editor only writes files for installed modules and languages; before, a crafted module name could write outside locales/
  * The current password is checked with password_verify() when changing it, and saving a user no longer re-hashes the stored password ([#386](https://github.com/web2project/web2project/issues/386))
  * The Active Sessions tab checks the session id before it reaches SQL
  * Projects the user is denied are no longer counted in the company list or the project tabs
* Data integrity
  * A refused delete no longer runs its cleanup. For example, a user who owned a project used to lose their login and preferences even though the delete was refused
  * Deleting a project removes its placeholder task from the parent project and its custom field values, and records the delete in the history
  * Deleting a user, event, forum, message or task log removes its custom field values, and only the deleted object's own values
  * Deleting a task removes its resource assignments. For a task with subtasks, the task's own assignments and dependencies are now removed too
  * Contacts are no longer saved with owner -1 when no one is logged in
* Users, permissions and LDAP
  * Removed duplicate permission entries so User and Calendar permissions can be granted ([#385](https://github.com/web2project/web2project/issues/385))
  * Users-module editors can save other users' preferences ([#385](https://github.com/web2project/web2project/issues/385))
  * Restored the "delete User" action on the user view ([#385](https://github.com/web2project/web2project/issues/385))
  * Changed passwords are stored as typed and the real result is reported; the strength meter loads again ([#386](https://github.com/web2project/web2project/issues/386))
  * LDAP: new users always get a contact and their password is hashed once; existing users without a contact get a placeholder ([#320](https://github.com/web2project/web2project/issues/320))
  * The access log records logins again, and the logout controls show on the Active Sessions tab
  * Logins are recorded as open until they end. Before, every login was stored as already ended, so logouts were never recorded and anyone who had ever logged in showed as "Online". Logging out in one browser no longer closes the user's other logins
  * A session's last-activity time is updated on every request, so active users are no longer logged out when the idle limit passes after login
* Projects and tasks
  * Fixed the project Task Logs tab crashing on first visit and for projects with subprojects
  * Fixed the project list being empty for users without full department rights
  * "Update projects status" preselects the current status and shows the result
  * Fixed a task's Child Tasks tab always being empty
  * Task reminders are sent again
  * Tasks moved by a dependency keep their dates in UTC instead of shifting by the user's offset (fix from Klaus Buecher)
  * Re-parenting a task moves its subtasks along, so dynamic task dates roll up correctly (fix from Klaus Buecher)
  * Moving a task to another project recalculates the old project's dynamic tasks (fix from Klaus Buecher)
  * Duplicating a file gives the copy the current user, date and its own history entry instead of the original's. The same root cause meant `CTask::copy()`/`deepCopy()` never updated the target project's task count or gave the copies their own parent and position in the tree (reported by Klaus Buecher)
  * The filter checkboxes on the To Do Gantt chart work ([#352](https://github.com/web2project/web2project/issues/352))
  * The project list's "LP" column shows the problem icon for projects with a task log flagged as a problem again; it always showed "-"
  * Moving a task to another project updates the old project's task count, including when the move leaves it with no tasks
* Dates and time zones
  * `w2p_Utilities_Date::convertTZ()` returned the wrong time and often the wrong date (16:13 UTC became 08:13 for Indianapolis instead of 12:13, and a January date became today). This fixes the times in task reminder e-mails, the "today" marker on the Gantt charts and the month calendar, and the Tasks per User report's date range
* Pagination and lists
  * Page links keep the current view and sort order
  * The Files list page links stay on the current project, company or task
  * The company Files tab shows that company's files
  * Selecting a project on the Files page no longer turns off the category tabs, so project and category can be combined
* Resources
  * Adding or editing a resource works on new installs. The installer left the Resources tables at an old module version, so saving failed with "Unknown column 'resource_description'" and there were no resource types (migration 068)
* Reports
  * Fixed the Project Statistics report crashing when there are no projects
  * The Project Statistics report counts unassigned tasks correctly; its "No Assignee" row never went past 1
  * The Task Logs reports apply their company filter, which was never read
  * Report messages and values that were computed but never output are shown
* Database and upgrades
  * Works with MySQL 8's default sql_mode (ONLY_FULL_GROUP_BY is turned off for web2project's connection)
  * Migration errors are reported instead of silently dropped. A fresh install now completes with none
  * Fixed migrations that errored on web2project databases or failed on strict servers (012, 033, 050/051, 056)
  * Migration 056 keeps the version history
  * Database version is now 68 (new migrations 063–068)
* PHP 8 and the error log
  * A logged-in crawl of 257 pages now produces no PHP warnings or notices (421 before the final round of fixes): list tables, reports, ProjectDesigner, the ACL view, the role list, the Task Logs tab and task saves (`array_sum()` on dependency lists)
  * Replaced the removed `$php_errormsg` and `mysql_get_client_info()`
  * Fixed the LDAP authenticator's method signature, a misspelled constant, a quoted preference name and a class/file name mismatch
  * Fixed the translation editor crash on strings of 40 or more characters

## Misc Changes/Improvements

* Removed
  * PDF output (reports, Gantt charts and forums)
  * File check-in/check-out ([#376](https://github.com/web2project/web2project/issues/376)), file change e-mail notifications and the file version field
  * The w2p-snowball and wps-redmond themes, and theme selection
  * includes/deprecated_functions.php (66 functions) and the 37 deprecated class aliases (CAppUI, CDate, DBQuery, CTitleBlock and others). Third-party code still using them will now fail with undefined-function or undefined-class errors
  * The remaining deprecated db_* helpers, replaced with w2p_Database_Connection
* Code cleanup
  * PHPDoc cleaned up across all classes, modules and tests
  * Removed commented-out PHP and JavaScript code and statements that could never run
  * Fixed invalid HTML (duplicate and malformed attributes, unclosed elements, table/form nesting, deprecated tags) and made the directory-guard index files valid HTML5. No deprecated HTML tags (such as `<font>` and `<center>`) remain in /modules
* Unit Tests
  * The include tests now run as part of phpunit.xml and use the PHPUnit 11 API
  * Removed tests for deleted deprecated methods and fixed broken assertions
  * The phploc build target writes a real XML report
* Version set to 5.0.0 (Composer package 5.0)

## Open/Known Issues

* The database layer - ADODB - is ancient and needs to be replaced. This is massive and touches every component.
* The date handling - PEAR Date - is ancient and needs to be updated to use Carbon.
* Names are still printed unescaped in some list tables and page titles (Companies, Projects and Tasks lists, calendar views, project and task views). This needs a central escaping pass.
* Uploaded files are stored inside the web root and protected only by an Apache 2.2-style `.htaccess` ([#394](https://github.com/web2project/web2project/issues/394), [#395](https://github.com/web2project/web2project/issues/395)).
* Public sign-up has no captcha or rate limit, and it e-mails the plaintext password ([#363](https://github.com/web2project/web2project/issues/363)).
* Session logout links are GET requests (admin only).
* Opening a file link while logged out gives a fatal error in `fileviewer.php`.
* The task tree joins user priorities and pins without the user, so the "U" column and the pin icon can show another user's values, and ProjectDesigner doesn't filter tasks by per-task permissions.
* The week view shades working days by column position, not by weekday.
* The placeholder task for an empty subproject gets the current date instead of the subproject's dates.
* The unit test suite runs 509 tests with 7 errors and 15 failures.

## v5.0.0-rc2 Release Notes {#release-notes-rc2}

**Release Date:** TBD

I> The primary goals of this release were security hardening (CSRF tokens on every data-changing request, session handling, SmartSearch injection fixes) and fixing regressions found in rc1 across the Gantt charts, calendars, and files/folders. Changes that affect upgrades or Add On modules: PHP 8.3 is now the minimum; migrations 070 and 071 run on upgrade; every POST with `dosql` must carry the `__nonce` form token (added automatically to `method=post` forms, but AJAX calls and hand-built links must send it); logout, session-ending and module admin links need the token too; the PDF export and `w2p_Output_PDFRenderer` are gone; `w2PgetParam()` no longer applies its never-working filter; `getCriticalTasksInverted()` and `strUTF8Decode()` are deprecated; table prefixes are explicitly unsupported; the session id is no longer passed in redirect URLs.

### New Features

* Files: the Folder Explorer is back as a Folders tab ([#406](https://github.com/web2project/web2project/issues/406), [#407](https://github.com/web2project/web2project/issues/407), [#408](https://github.com/web2project/web2project/issues/408))
* Files: a folder field on the Add/Edit File form, so files can be moved between folders ([#405](https://github.com/web2project/web2project/issues/405))
* Signup: self-hosted bot protection, and signup stops after the duplicate checks ([#363](https://github.com/web2project/web2project/issues/363))
* Print stylesheet: pages print cleanly from the browser, replacing the PDF export ([#393](https://github.com/web2project/web2project/issues/393))
* Calendars shade non-working days from `cal_working_days` and holidays; the Bootstrap theme marks them distinctly from task days
* The header search box runs SmartSearch directly, and SmartSearch is hidden from the menu (migration 071)
* Lost password works again and generates unguessable passwords

### Fixes/Bugs Closed

* Security
  * Check a form token on every request that changes data (CSRF)
  * Logout, ending sessions and module admin links need the form token ([#400](https://github.com/web2project/web2project/issues/400))
  * Stop putting the session id in redirect URLs
  * Regenerate the session id when a user logs in
  * Set Secure, HttpOnly and SameSite on the session cookie
  * Only link to http(s), ftp and mailto URLs, and escape them: stored XSS through URL fields ([#401](https://github.com/web2project/web2project/issues/401))
  * Contacts: quote the e-mail address in the duplicate check: SQL injection ([#402](https://github.com/web2project/web2project/issues/402))
  * SmartSearch: quote search terms in the SQL: SQL injection
  * SmartSearch: escape the keywords echoed back into the search form: XSS
  * SmartSearch: escape record values in the results list: stored XSS
  * `w2PgetParam()`: drop the filter that never matched; fix callers that relied on it ([#403](https://github.com/web2project/web2project/issues/403))
* Gantt
  * Draw all text in DejaVu Sans so non-Latin-1 names render; fit header rows to the chart width and draw CJK text; draw mixed-script labels in runs and keep right-edge captions in
  * Draw the Today line in the middle of today
  * Dependency arrows on every chart; fit the task table to narrow charts
  * Qualify `task_id` in the task permission filter
  * Project Gantt tab and Project Designer show every task, not just the viewer's
  * Sub-projects gantt: fix the PHP 8 fatal and show tasks again; indent milestones; show each task's own progress
  * Project Designer: no `getStyle('td_sample')` error on load ([#431](https://github.com/web2project/web2project/issues/431))
* Calendars, events and dates
  * Calendars mark today again
  * Week view shows the week the tasks and events are loaded for
  * Minicals draw days of the previous/next month as plain empty days
  * Task dates: stop double-encoding the working-day names
  * `Date::format()`: pad `%I` to two digits ([#426](https://github.com/web2project/web2project/issues/426))
* Files and folders
  * No folder can be moved into itself; fix the folder edit page ([#409](https://github.com/web2project/web2project/issues/409), [#410](https://github.com/web2project/web2project/issues/410))
  * A duplicated file keeps its project and folder ([#411](https://github.com/web2project/web2project/issues/411))
  * Folder delete asks once and deletes through the Files module ([#432](https://github.com/web2project/web2project/issues/432))
* Mail, contacts, forums and system
  * Mail: send queued mail instead of queueing it again; fix Cc/Bcc ([#424](https://github.com/web2project/web2project/issues/424), [#425](https://github.com/web2project/web2project/issues/425))
  * Contacts cron: fill in missing display names without `load()`/`store()`, so queuescanner.php no longer crashes ([#399](https://github.com/web2project/web2project/issues/399))
  * Contacts list and contact view show free-text countries without a warning ([#430](https://github.com/web2project/web2project/issues/430))
  * Forum reply form: define `$df`/`$tf` and show the message being replied to ([#429](https://github.com/web2project/web2project/issues/429))
  * Forums keep the forum's message count when a message is posted
  * New custom field form initialises its field values ([#428](https://github.com/web2project/web2project/issues/428))
  * System Lookup Keys: adding, editing and deleting keys works again
  * Permissions: no warnings when an item's module is inactive
  * `BaseObject`: an object restored from the session gets a new query
  * Sub-projects list passes its classes as classes, not as the table id
* SmartSearch
  * A search for `0` is no longer dropped; empty search terms are dropped instead of matching everything
  * Search terms are escaped properly when highlighting results
  * The accent-insensitive pattern is rebuilt with real UTF-8
  * Array-valued keywords and module lists are ignored
