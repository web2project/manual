## Other Modules {#module-other}

This chapter covers the smaller core modules that don't need a chapter of their own.

### History {#module-history}

The History module keeps a record of what changes in Web2Project: each time someone creates, updates or deletes a company, project, task, contact, file, link or other item, it notes when it happened, what kind of item it was, the item's name and who did it. It is useful for answering "who changed this, and when?"

I> The History module is active but hidden from the sidebar by default. Changes are recorded whenever the module is active. To open it from the sidebar, go to System Admin → View Modules and set History to "visible"; it then appears under *Tools*. To stop recording changes, disable the module there. The *Log Changes* setting in System Configuration is no longer used.

#### Viewing the History

{float=right}
![The History page](images/history/index.png)

The History page lists the recorded changes, oldest first, split into pages. Use the **Changes to** filter at the top to choose which changes to show: "Show all", one module at a time (Projects is selected at first), or "Login/Logouts".

The columns are:

* **Date**: when the change was made
* **Module**: the kind of item that changed
* **Action**: Create, Update or Delete
* **Item**: the item's name when it was saved. Deletes are recorded without a name.
* **Actor**: the user who made the change

You only see changes to items you are allowed to view.

The Login/Logouts filter shows the sessions that administrators ended from the Active Sessions tab in User Admin. Ordinary logins and logouts are recorded in the [User Log](#module-users) instead.

#### History on a project

{float=right}
![A project's History tab](images/history/project_tab.png)

Projects also have a History tab, which lists the changes to that project.

### Help {#module-help}

Many fields and icons in Web2Project show a short explanation when you hover over them. In System Configuration, every setting has an (i) icon with a description.

{float=right}
![The Help window](images/help/window.png)

For anything else, select the **Help** icon (a question mark) in the bar at the top of every page. On narrow screens it is in the user menu. It opens a small window with links to where to find help:

* the [Web2Project documentation](https://docs.web2project.net/) site, which explains each module and feature;
* [GitHub Discussions](https://github.com/orgs/web2project/discussions), for questions;
* the [issue tracker](https://github.com/web2project/web2project/issues), for known problems and suggestions.

The Help window's text comes from `locales/{language}/help.php`, so a translation can provide its own version. The Help module is active but hidden from the sidebar by default; the icon in the header works either way.
